# ProvidAPT 架构设计

## 概述

ProvidAPT 是一个基于 eBPF LSM 的 Linux 全系统溯源记录工具，灵感来自 CamFlow，专注于 APT 攻击检测场景。

## 架构层级

```
┌─────────────────────────────────────────────────┐
│                  用户态 (Go)                      │
│                                                   │
│  ┌──────────┐  ┌──────────┐  ┌────────────────┐ │
│  │providaptd│  │providaptl│  │  REST/gRPC API │ │
│  └────┬─────┘  └──────────┘  └───────┬────────┘ │
│       │                               │          │
│  ┌────▼───────────────────────────────▼────────┐ │
│  │              Event Pipeline                  │ │
│  │  RingBuf → Parse → Enrich → Graph → Store   │ │
│  └───────────────────┬─────────────────────────┘ │
└──────────────────────┼───────────────────────────┘
                       │ BPF RingBuf (无锁共享内存)
┌──────────────────────┼───────────────────────────┐
│  eBPF 内核态 (C)     │                           │
│                       │                           │
│  ┌────────────┬───────▼───────┬────────────────┐ │
│  │ LSM Hooks  │ Tracepoints   │   kprobes      │ │
│  │ task_alloc │ sched/fork    │   do_unlinkat   │ │
│  │ file_open  │ sys_enter_*   │   security_cap  │ │
│  │ bprm_check │               │                 │ │
│  │ socket_con │               │                 │ │
│  └────────────┴───────────────┴────────────────┘ │
└───────────────────────────────────────────────────┘
```

## 核心数据流

1. **事件捕获**: eBPF 程序挂载在 LSM 钩子/tracepoint/kprobe 上,捕获系统关键操作
2. **数据传输**: 通过 BPF RingBuf (无锁,多生产者/单消费者) 将事件从内核推送到用户态
3. **事件解析**: Go 用户态程序读取 RingBuf,反序列化为结构化 event
4. **溯源图谱**: 事件流经 Provenance Graph 构建 DAG,维护进程/文件/网络节点关系
5. **持久化**: 事件写入 NDJSON (开发) 或 Parquet (生产) 格式文件
6. **对外接口**: gRPC 供 SIEM 集成,REST API 供管理查询

## 安全设计

- 仅读的 eBPF 程序,不修改内核行为
- 支持按需 Hook 开关,避免不必要的性能开销
- 所有事件带时间戳和进程上下文,满足审计链完整性要求

## Maintenance Notes

- Root-level progress logs were removed because they duplicated release and
  handoff records under `docs/project/`.
- Current readiness evidence is generated by Makefile gates, including visual
  regression, capture/enrichment coverage, artifact signing, activation server,
  policy approval, backup readiness, support bundle, and deployment diagnostics.
- Historical release evidence is kept when it records a published or candidate
  release decision; short-lived local validation snapshots should be folded into
  `macbook-ai-development-handoff.md` or a dated release evidence record.

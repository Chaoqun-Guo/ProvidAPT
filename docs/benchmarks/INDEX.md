# 性能基准

本节汇总 ProvidAPT 在不同环境下的性能测试数据与方法说明。

## 文档列表

| 文档 | 说明 |
| --- | --- |

## 关键指标摘要

| 指标 | 典型值 | 备注 |
| --- | --- | --- |
| 事件吞吐 | 50K - 150K ops/s | 取决于 Ring Buffer 与内核版本 |
| 平均延迟 | < 5 μs | eBPF 到用户态传递延迟 |
| CPU 开销 | 1% - 3% | 典型单机场景 |
| 内存开销 | 约 200 MB | 包含缓存与存储引擎 |

## 测试方法

性能测试基于 `test/benchmark/` 下的自动化脚本与场景集执行。
